快速測試步驟（重要！）

ℹ️ 完整流程必須按順序操作，才能完成跨裝置同步驗證
  1. 兩端設定相同的同步碼和 API 位址
    • 電腦端：同步碼 + API 位址 + 保存設定
    • 手機端：完全相同的同步碼 + API 位址 + 保存設定
  2. 電腦端執行操作
    • 點擊「1️⃣ 執行操作」→ 新增/修改/刪除資料
    • 日誌中會顯示 ✓ 已保存到本地
  3. 電腦端推送到雲端（最關鍵！）
    • 點擊「2️⃣ 推送到雲端」→ 資料上傳到 API
    • 日誌中會顯示 ✅ 已推送到雲端
    • 沒有這步，手機端永遠拉不到資料！
  4. 手機端拉取最新資料
    • 點擊「拉取最新資料」→ 從 API 下載資料
    • 查看下方表格的個案數是否增加
  5. 驗證同步結果
    • 手機本地資料表應顯示新增的個案記錄
    • 點「對比電腦/手機資料」查看詳細
